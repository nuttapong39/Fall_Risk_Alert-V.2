อัปเดต MedAlert ให้ทันสมัย

ดึงโค้ดเวอร์ชันล่าสุดจาก GitHub มาใช้ในไม่กี่คลิก — โดยไม่แตะข้อมูลหรือการตั้งค่าเฉพาะของโรงพยาบาลเลยสักไฟล์

สำรองไฟล์ให้ อัตโนมัติทุกครั้ง ไม่แตะ secrets/ และ logs/ รองรับทั้ง Git และ ZIP

ระบบอัปเดตทำงานอย่างไร

กดปุ่มเดียวในหน้าเว็บ ระบบจะทำ 4 ขั้นตอนนี้ให้อัตโนมัติเบื้องหลัง — ไม่ต้องเข้าใจรายละเอียดทางเทคนิคก็ใช้ได้

1

อัปเดตผ่านหน้าเว็บ (ปกติ)

สำหรับเครื่องที่มีการ์ด "เวอร์ชันระบบ" ในหน้าตั้งค่าอยู่แล้ว — ใช้วิธีนี้ทุกครั้ง

  1. เข้าเมนู ตั้งค่าระบบ แล้วเลื่อนไปที่การ์ด "เวอร์ชันระบบ"
  2. กด "ตรวจสอบอัปเดต" — ระบบจะเทียบเวอร์ชันปัจจุบันกับ GitHub ให้
  3. ถ้ามีเวอร์ชันใหม่กว่า จะมีช่องให้พิมพ์คำว่า UPDATE เพื่อยืนยัน
  4. กด "อัปเดตตอนนี้" แล้วยืนยันอีกครั้งในกล่องเตือน — แถบความคืบหน้าจะขึ้นให้เห็นทันที
  5. รอแถบขึ้นจนเต็ม 100% แล้วกดปุ่ม "Update Success" ที่โผล่ขึ้นมาเพื่อยืนยัน (กลุ่ม LINE/Telegram ของ รพ. จะได้รับแจ้งเตือนอัตโนมัติด้วยเช่นกัน)

i
รีเฟรชหน้าหรือปิดแท็บระหว่างรอได้ไม่มีปัญหา — ถ้าการอัปเดตใช้เวลานาน (เช่น เน็ตช้าตอนดาวน์โหลด) แล้วสลับแท็บหรือรีเฟรชไปเปิดหน้า "ตั้งค่าระบบ" ใหม่ ระบบจะดึงสถานะล่าสุดมาแสดงแถบความคืบหน้าให้อัตโนมัติทันที ไม่ต้องกดปุ่มซ้ำ
!
ห้ามปิดเครื่อง server ระหว่างอัปเดต และถ้าเคยแก้ไฟล์ PHP/SQL ตรงๆ (นอกเหนือจากตั้งค่าผ่านหน้าเว็บ) การอัปเดตจะเขียนทับสิ่งนั้นทิ้ง — การปรับแต่งทุกอย่างของ MedAlert ควรทำผ่านหน้าเว็บเท่านั้น
2

เวอร์ชันเก่ามาก (ยังไม่มีการ์ดนี้)

ถ้าติดตั้งไว้ตั้งแต่ก่อนมีระบบอัปเดตนี้ หน้าตั้งค่าจะยังไม่มีการ์ดให้กด — ต้อง "จุดชนวน" ด้วยมือครั้งเดียวเท่านั้น

  1. เปิดโฟลเดอร์ C:\xampp\htdocs\Fall_Risk_Alert-main\task\ บนเครื่อง server
  2. ดาวน์โหลด 2 ไฟล์นี้มาวางในโฟลเดอร์ task\ เดิม (เขียนทับได้ถ้ามีของเก่า):
    https://raw.githubusercontent.com/nuttapong39/Fall_Risk_Alert-V.2/master/task/update.bat
    https://raw.githubusercontent.com/nuttapong39/Fall_Risk_Alert-V.2/master/task/update.ps1

    หรือถ้าถนัดใช้คำสั่งมากกว่าเปิดเบราว์เซอร์ — เปิด PowerShell แล้ววางคำสั่งนี้ (ดึงตรงเข้าโฟลเดอร์ให้เลย ไม่ต้องดาวน์โหลดเอง):

    PowerShell
    cd C:\xampp\htdocs\Fall_Risk_Alert-main\task
    Invoke-WebRequest -Uri "https://raw.githubusercontent.com/nuttapong39/Fall_Risk_Alert-V.2/master/task/update.bat" -OutFile "update.bat"
    Invoke-WebRequest -Uri "https://raw.githubusercontent.com/nuttapong39/Fall_Risk_Alert-V.2/master/task/update.ps1" -OutFile "update.ps1"
  3. ดับเบิลคลิก update.bat (ไม่ต้องขอสิทธิ์ Administrator)
  4. รอจนจบหน้าต่างขึ้น Done. — สคริปต์สำรองไฟล์แล้วดึงโค้ดทั้งชุดปัจจุบันมาแทนที่ให้เอง
i
รอบนี้จะเป็นการกระโดดข้ามหลายรีลีสพร้อมกัน (ไม่ใช่ทีละเวอร์ชัน) แต่ปลอดภัยเหมือนอัปเดตปกติทุกประการ — หลังจากนี้การ์ด "เวอร์ชันระบบ" จะโผล่ในหน้าตั้งค่า และใช้ วิธีที่ 1 ได้ตลอดไปในรอบถัดๆ ไป

ถ้ามีปัญหา

อาการที่พบบ่อยและวิธีแก้

◆ กด "อัปเดตตอนนี้" แล้วไม่มีอะไรเกิดขึ้น

แก้: server อาจปิดฟังก์ชันรันโปรแกรมภายนอกไว้ — ระบบจะแจ้งให้ไปดับเบิลคลิก task\update.bat เองแทน (สคริปต์ตัวเดียวกัน)

✕ อัปเดตพังกลางทาง

แก้: ไฟล์สำรองอยู่ที่ C:\xampp\htdocs\_backup\Fall_Risk_Alert-main_<วันที่เวลา>\ — copy ทับกลับไปที่ C:\xampp\htdocs\Fall_Risk_Alert-main ได้เลย

▲ กด "ตรวจสอบอัปเดต" แล้วขึ้น "เชื่อมต่อ GitHub ไม่สำเร็จ"

แก้: เครื่อง server ต้องออกอินเทอร์เน็ตไปยัง github.com/raw.githubusercontent.com ได้ — เช็ค firewall/proxy ขององค์กร

▲ อัปเดตเสร็จแต่เวอร์ชันในหน้าเว็บไม่เปลี่ยน

แก้: รีเฟรชหน้าเว็บ (Ctrl+F5) — ถ้ายังไม่เปลี่ยน ดู VERSION ในโฟลเดอร์ติดตั้งว่าอัปเดตจริงไหม

▲ แถบความคืบหน้าค้างอยู่แถว 90-95% นานผิดปกติ

ปกติ: ช่วงแรกแถบจะประมาณจากเวลาที่ผ่านไป เพดานไว้ที่ 95% จนกว่าจะยืนยันว่าเสร็จจริง แก้: รอเพิ่มอีกสักครู่ (โดยเฉพาะถ้าเน็ตช้าตอนดาวน์โหลด ZIP) แล้วลองรีเฟรชหน้าดูเวอร์ชัน

ดู log ละเอียดได้ที่

C:\xampp\htdocs\Fall_Risk_Alert-main\logs\update_status.json   :: สถานะล่าสุด
C:\xampp\htdocs\Fall_Risk_Alert-main\logs\update_<วันที่เวลา>.log   :: log เต็มของรอบนั้น

Checklist ก่อน/หลังอัปเดต

  1. 01เครื่อง server ออกอินเทอร์เน็ตได้ (ไปยัง github.com)
  2. 02ไม่มีคนกำลังใช้งานระบบพร้อมกันจำนวนมาก (เผื่อเวลาสำรองไฟล์)
  3. 03กด "ตรวจสอบอัปเดต" → พิมพ์ UPDATE ยืนยัน → กด "อัปเดตตอนนี้"
  4. 04ห้ามปิดเครื่อง server จนกว่าแถบความคืบหน้าจะขึ้น 100% และกดปุ่ม "Update Success" แล้ว
  5. 05ตรวจว่ากลุ่ม LINE/Telegram ของ รพ. ได้รับข้อความแจ้งเตือน "อัปเดตระบบสำเร็จ" อัตโนมัติ
  6. 06รีเฟรชหน้าเว็บ ยืนยันเวอร์ชันใหม่ขึ้นถูกต้อง
  7. 07ทดสอบ "ส่งซ้ำทันที" สักเคสในโมดูลที่ใช้บ่อย ยืนยันยังส่งเข้า LINE/Telegram ได้ปกติ
  8. 08อ่าน CHANGELOG.md ดูว่ารีลีสนี้เปลี่ยนอะไรบ้าง
