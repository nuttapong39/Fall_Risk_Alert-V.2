ติดตั้ง MedAlert ทีละขั้น

ระบบแจ้งเตือนผู้ป่วยกลุ่มเสี่ยงเข้า LINE & Telegram อัตโนมัติ — คู่มือนี้พา รพ.ที่นำระบบไปใช้ ติดตั้งครบทั้ง 10 โมดูลตั้งแต่ศูนย์ จบใน 9 ขั้นตอน

XAMPP 8.2 / PHP 8.2 10 โมดูลแจ้งเตือน ติดตั้ง ~30 นาที Windows 10 / 11 / Server

ติดตั้ง XAMPP

ติดตั้งเว็บเซิร์ฟเวอร์ (Apache + PHP + MySQL) ในชุดเดียว

  1. ดาวน์โหลด XAMPP 8.2.x จาก apachefriends.org
  2. ติดตั้งลงที่ C:\xampp (ใช้ตำแหน่งมาตรฐานนี้)
  3. เปิด XAMPP Control Panel → กด Start ที่ Apache และ MySQL
  4. ทดสอบเปิด http://localhost → เห็นหน้า XAMPP = พร้อมใช้งาน

เปิด PHP Extensions

✓
วิธีง่าย (แนะนำ): ดับเบิลคลิก enable_php_extensions.bat ในโฟลเดอร์โปรเจกต์ → กด Yes ที่ UAC → สคริปต์ เปิด extension ที่จำเป็นให้ครบ + สำรอง php.ini + Restart Apache ให้อัตโนมัติ ไม่ต้องแก้ไฟล์เอง

หรือแก้เอง: เปิด C:\xampp\php\php.ini ให้บรรทัดเหล่านี้ ไม่มี เครื่องหมาย ; นำหน้า แล้ว Restart Apache

; จำเป็นทุกการติดตั้ง
extension=curl
extension=pdo_mysql
extension=mbstring
; สำหรับ HOSxP ที่เป็น PostgreSQL (XE4)
extension=pdo_pgsql
extension=pgsql
!
ปรับค่าประสิทธิภาพในไฟล์เดียวกันด้วย: max_execution_time=300 และ memory_limit=256M

ตั้งเวลาอัตโนมัติ (Scheduled Tasks)

ให้ worker ทั้ง 10 โมดูลรันเองตามเวลา — ติดตั้งทีเดียวทั้งหมดด้วยสคริปต์เดียว

  1. เข้าโฟลเดอร์ C:\xampp\htdocs\Fall_Risk_Alert-main\task\
  2. ดับเบิลคลิก install_tasks.bat
  3. กด Yes ที่หน้าต่าง UAC (ขอสิทธิ์ Administrator อัตโนมัติ)

ปรับค่าเฉพาะโรงพยาบาล

รหัส Lab / รหัสยา / เกณฑ์ค่าวิกฤต ต่างกันในแต่ละ รพ. — แก้ผ่านหน้าเว็บได้เลย ไม่ต้องแก้โค้ด

ทุกโมดูล (COVID-19, อุบัติเหตุ, ยาอันตราย, Sexual Assault, เลปโต, สครับ, ไข้เลือดออก, จิตเวช, หกล้ม, Lab วิกฤตห้องยา) มีปุ่ม "แก้ไขเงื่อนไขดึงข้อมูล" อยู่มุมขวาบนของหน้าคิว/หน้าโมดูลนั้น ๆ — กดแล้วแก้รหัส/เกณฑ์ในหน้าต่างที่เด้งขึ้นมาได้ทันที มีผลทั้งการส่งอัตโนมัติ (worker) และปุ่ม Sync/Import พร้อมกัน (ค่า default = ค่าที่ระบบตั้งไว้ตั้งแต่ต้น จนกว่าจะมีคนแก้)

ในหน้าต่างนั้นมีปุ่ม "ทดสอบ (นับผลย้อนหลัง 30 วัน)" ให้ลองนับผลก่อนกดบันทึกจริง เพื่อเช็คว่ารหัสที่กรอกดึงข้อมูลได้ตามคาด

i
หา lab_items_code ได้ที่ phpMyAdmin: SELECT lab_items_code, lab_items_name FROM lab_items WHERE lab_items_name LIKE '%covid%' แล้วนำรหัสที่ได้ไปกรอกในหน้าต่างแก้ไขเงื่อนไข

แก้ปัญหาที่พบบ่อย

อาการที่เจอจริงระหว่างติดตั้ง พร้อมวิธีแก้

✕ เข้าเว็บแล้วขึ้น “DB connect failed”

แก้: ตรวจ secrets/db_config.json ก้อน medalert — host/user/pass ถูกไหม, MySQL service Start อยู่ไหม (ทดสอบที่ phpMyAdmin)

▲ กด “ส่งซ้ำ” แล้วเคสค้าง Pending ตลอด

แก้: เช็คว่า มี Scheduled Task ของโมดูลนั้นจริงไหม (taskschd.msc) — ปุ่ม Requeue แค่รีเซ็ตสถานะ ต้องมี Task รัน worker ถึงจะส่ง

▲ Telegram: ทดสอบขึ้น แต่เคสจริงไม่เข้า

แก้: ตั้งค่ายังไม่ ติ๊กเปิดใช้งาน — ปุ่มทดสอบไม่เช็คสวิตช์นี้ แต่การ mirror จริงเช็ค ต้องเปิด + บันทึก

✕ MOPH ตอบ 200 แต่ LINE ไม่เข้ากลุ่ม

แก้: key ผูกกับกลุ่มผิด / OA ยังไม่อยู่ในกลุ่ม · Flex มี rgba() (LINE รับเฉพาะ #RRGGBB) · key ว่าง = ยิงเข้ากลุ่ม default

◆ Task รันแล้ว log ไม่ขยับ / ว่าง

แก้: ตรวจ Start in ของ Task = C:\xampp\htdocs\Fall_Risk_Alert-main และ php.ini เปิด curl/pdo_mysql แล้ว

◆ Import แล้วไม่พบผู้ป่วย

แก้: ตรวจ lab_items_code ให้ตรง HOSxP (ขั้นที่ 9) · ช่วงวันที่ default ย้อนหลัง 7 วัน · user MySQL มีสิทธิ์ SELECT ตาราง HOSxP

ดู log ทั้งหมดได้ที่ logs\

type C:\xampp\htdocs\Fall_Risk_Alert-main\logs\fracture_task_run.log   :: การรัน Task
type C:\xampp\htdocs\Fall_Risk_Alert-main\logs\moph_alert_*.log        :: การส่ง MOPH ราย module

Checklist สรุป

ติ๊กให้ครบก่อนส่งมอบระบบให้หน่วยงาน

  1. 01ติดตั้ง XAMPP ที่ C:\xampp · Start Apache + MySQL · เปิด extension ใน php.ini
  2. 02วางไฟล์ที่ C:\xampp\htdocs\Fall_Risk_Alert-main
  3. 03เปิดเว็บ → หน้า Setup → กรอก HOSxP + MedAlert_DB + admin → กด Setup (สร้าง DB/ตาราง/admin อัตโนมัติ)
  4. 04Login ด้วยบัญชี admin ที่สร้าง
  5. 05ตั้งชื่อโรงพยาบาลที่ ตั้งค่าระบบ
  6. 06กรอก MOPH client/secret key ทุกโมดูล + ตั้ง Telegram (เปิดใช้งาน)
  7. 07ทดสอบ Send Now → ยืนยันเข้ากลุ่ม LINE + Telegram จริง
  8. 08รัน task\install_tasks.bat → “10 installed, 0 failed”
  9. 09ปรับ lab_items_code / icode ยา ให้ตรง HOSxP
