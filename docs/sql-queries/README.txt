======================================================================
 MedAlert · SQL Query ดึงผู้ป่วยจาก HOSxP (สำหรับรันใน Navicat)
======================================================================

โฟลเดอร์นี้เก็บ query ของแต่ละ module แยกไฟล์ .txt — เป็น SQL ตัวจริง
ที่ระบบใช้ดึงเคสจาก HOSxP เข้าคิวแจ้งเตือน (สกัดมาจาก sources/*_source.php)

Dialect : PostgreSQL (HOSxP XE4) — เปิดใน Navicat for PostgreSQL
ค่าในไฟล์ : ใส่ค่าตัวอย่างไว้แล้ว (ช่วงวันที่ = เดือนปัจจุบัน) → กด Run ได้ทันที

----------------------------------------------------------------------
วิธีใช้
----------------------------------------------------------------------
1. เปิด Navicat → เชื่อมต่อฐานข้อมูล HOSxP (XE4)
2. New Query → เปิด/วางเนื้อหาไฟล์ .txt ของ module ที่ต้องการ
3. แก้ค่าตามต้องการ แล้วกด Run:
     • ช่วงวันที่  BETWEEN 'YYYY-MM-DD' AND 'YYYY-MM-DD'
     • รหัส lab / pttype / icode  ← ให้ตรงกับรหัสใน HOSxP ของโรงพยาบาลท่าน

ใช้ตรวจสอบว่า "ระบบจะดึงเคสไหนบ้าง" ก่อนตั้งค่า / เทียบผลกับที่คาดไว้
(ถ้ารหัส lab/pttype ไม่ตรง จะดึงไม่ครบ หรือได้ผิดกลุ่ม)

หมายเหตุ
----------------------------------------------------------------------
- เป็น query อ่านอย่างเดียว (SELECT) — ปลอดภัยต่อ HOSxP ไม่แก้ข้อมูล
- ถ้า HOSxP เป็น MySQL (V3/PCU) query จะต่างเล็กน้อย (GROUP BY/YEAR()) —
  ดูตัวจริงได้ใน sources/<module>_source.php สาขา mysql
- accident: cron ดึง "ผู้ป่วยใน (ipt)" · ปุ่ม Import ในเว็บดึง "ผู้ป่วยนอก (ovst)"
